# 仕様の変遷（旧仕様と現行仕様の差分）

設計判断を後から追えるよう、置き換わった仕様・撤回した判断・記録の食い違いを「なぜ変えたか」とともに残す。新しい仕様が常に優先する。

出典：git 履歴（2026-05-07〜07-30、84 コミット）、開発ログ（2026-06-25〜07-07）、本番 DB（2026-10-17 時点）。2026-05-07〜06-09 と 2026-07-09 以降は開発ログが無く、コミットメッセージのみが根拠。

## 1. アーキテクチャ・技術選定

| 項目 | 旧 | 新 | 変更日 | 理由 |
|---|---|---|---|---|
| バックエンド | Node.js + Express の REST API | フロントから Supabase を直接利用 | 2026-06-08 | Netlify の静的ホスティングで動かし、サーバー運用を無くすため |
| Express のコード | 廃止 | 本番未使用のまま残置（削除は未決） | 2026-06-27 / 07-04 | 削除判断を保留。ローカルに未コミットの安全化修正あり |
| 画像の中継 | Express にプロキシを追加する案 | Netlify Function `image-proxy` | 2026-07-04 | Express は本番に存在しないため |
| React / Router | React 18 / Router v6（旧 README の記述） | React 19.2 / Router 7.15（`package.json`） | — | 仕様の変更ではなく旧 README の誤り。git 上は最初のコミット（`d857f6a`）から React 19 |
| 並び替え | ネイティブ HTML5 ドラッグ | @dnd-kit | 2026-06-09 | 動きが滑らかで、並び順の一意制約違反を避けやすい |
| ネイティブ化 | 配布方式はリリース直前に決める | Capacitor（別ブランチ） | 2026-07-04 決定・07-06 実装 | iOS / Android 両対応。TWA は Android 専用 |

## 2. 外部 API

| 項目 | 旧 | 新 | 変更日 | 理由 |
|---|---|---|---|---|
| アニメ画像 | Jikan API v4 | AniList GraphQL | 2026-06-26 | Jikan は 504 が頻発（実測 4 件中 3 件）、日本語検索に弱い |
| 曲画像の採用基準 | iTunes の先頭 1 件をそのまま採用 | 10 件取得 + 類似度スコア（0.72 未満は不採用） | 2026-06-26 | 誤った画像が付いていた。「誤画像より NO IMAGE」 |
| ボカロ曲の画像 | iTunes 画像をスキップ | 全カテゴリで iTunes を使う | 2026-06-25 | 初音ミク曲 100 件中 88 件がヒットした |
| アニメ・アーティスト画像の採用基準 | 先頭候補を採用（スコアなし） | 類似度スコア → アニメは同点時に人気度で決定 | 2026-07-21 / 07-30 | 続編・スピンオフの画像が付く誤りを検証で発見 |
| アーティストの英語名 | iTunes（日本語名が返るだけで使えず見送り） | MusicBrainz | 2026-07-02 | MusicBrainz は英語エイリアスを持つ |

## 3. データ・DB

| 項目 | 旧 | 新 | 変更日 | 理由 |
|---|---|---|---|---|
| 収録範囲 | アニソンのみ | アニソン・ボカロ・VTuber・ゲーム曲 | 2026-06-25〜26 | ロードマップの DB 拡張を前倒し |
| VTuber のオリジナル曲判定 | 事務所照合で「一致」のみ（1,623 曲） | 曲名・アルバム名のカバー判定（4,704 曲） | 2026-06-27 | 中小事務所のオリジナル曲が大量に漏れていた |
| 年代検索 | 年代で**並び替え** | 年代で**絞り込み** | 2026-06-26 | オーナーの訂正（欲しいのは検索） |
| アーティスト詳細の曲一覧 | 上限 100 件 | 30 件ずつページング | 2026-06-25 | 初音ミク（3 万曲超）で頭打ちになった |
| 画像キャッシュの書き込み権限 | ログインユーザーのみ、行単位 | 未ログインも可、ただし列単位で限定 + CHECK 制約 | 2026-06-27 | 実質キャッシュされていなかった。行単位では曲名なども書き換えられた |
| users の読み取り | 全件公開（`users_select_all`） | 公開設定の人のみ → さらに生年・性別は誰も読めない | 2026-06-27 / 07-07 | 公開設定を無視して全員の生年・性別が読めた |
| マイリスト | 曲リストのみ | 曲リスト / アニメリスト（`list_type`） | 2026-07-06 | オーナー要望。曲とアニメは同じリストに混ぜない |
| 検索の一致方式 | 部分一致のみ。並びは曲・アーティストが ID 順、アニメが放送年順 | 部分一致 + 誤字許容・関連度順（ゲームは対象外） | 2026-07-21 | 誤字に弱く、近い候補が上に来なかった |

## 5. 収益化・広告

| 項目 | 旧 | 新 | 変更日 | 理由 |
|---|---|---|---|---|
| 広告の表示 | 実装したら表示 | **既定は非表示**、本物の広告接続後に環境変数で有効化 | 2026-07-07 | ダミー広告をユーザーに見せない（オーナー判断） |
| 広告の装飾 | 広告そのものに電光掲示板エフェクト | 枠の外側だけ装飾 | 2026-07-07 | 広告本体の加工は規約違反になりうる（誤クリック誘発）。iframe 内には技術的にも届かない |
| ホームの広告位置 | おすすめ・今週人気・新着アニメ → 広告 → ランキング・最近追加・おすすめ曲 | おすすめ → 広告 → ランキング | 2026-10-17 | 仕様の簡素化（いずれもセクション未実装） |
| 曲詳細の広告位置 | ジャケット・曲情報・各サービスのボタン・レビュー・コメント → 広告 → 関連曲 | レビュー → 広告 → 関連曲 | 2026-10-17 | 同上 |
| アニメ詳細の広告位置 | 作品情報・OP・ED・挿入歌 → 広告 → レビュー・関連作品（実装は「作品情報の直後」と解釈） | 挿入歌一覧 → 広告 → レビュー | 2026-10-17 | 仕様の明確化。**現在の実装は曲一覧の上にあり要修正** |
| ランキングの広告頻度 | 3〜5 件ごと | 4 件ごと（設定のみ） | 2026-07-07 | ランキングページ未実装 |
| 不採用の広告 | インタースティシャル・強制動画・リワード・画面遷移ごと・閉じるまで操作不可 | 同左 + 全画面広告を明記 | 2026-10-17 | 方針の再確認 |
| 収益化の順序 | 広告 → プレミアム（それ以外は記録なし） | 広告 → プレミアム → アフィリエイト → ライブ・イベント送客 → スポンサー | 2026-10-17 | 次段階を初めて方針化 |
